# Bio-Entry

build an employee clocking system using finger print systems. Employees only need to enter their finger print to register the time they entered the office. The website should be able to register new employers so that it will know which user print is captured. Their full names, image, address, phone number, address, etc should be captured during registering employees. Build a powerfull dashboard as well and finish the entire project
